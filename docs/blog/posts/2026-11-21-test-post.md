how do i insert an image

There are three ways, so use whichever is easiest. First, click in the **Post** box on an empty line where you want the picture.

1. **Drag it in.** Drag the image file from File Explorer and drop it into the Post box.
2. **Paste a screenshot.** Take one with **Win+Shift+S**, click the empty line, and press **Ctrl+V**.
3. **Use the menu.** Type **/** on an empty line and choose **Image**. That opens a window where you can upload a file from your computer or pick one you've used before.

Each picture is saved with your site automatically when you click **Save**. If you click on a picture, you'll see an **ALT** button. Use it to add a short description of the image for people who can't see it.
