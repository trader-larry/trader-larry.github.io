# Dividend Dashboard is on GitHub

I've published the first version of my
[Dividend Dashboard](../../projects/dividend-dashboard/index.md): a local, no-account
dashboard for dividend ETFs, funds and stocks.

((more))

It started as a script for my own holdings and grew into a full page with income
projections, an ex-dividend calendar, fund overlap, symbol comparison and a
research tab. Everything runs on your own computer with only Python's standard
library, so there's nothing to install beyond Python itself.

What's in this first release:

- Seven tabs, from Price & fund to Research ([screenshots](../../projects/dividend-dashboard/screenshots.md))
- Import from broker CSVs with a preview of every change, and automatic backups
- A shared holdings file through OneDrive, Dropbox or iCloud for multiple computers
- A [getting-started guide](../../projects/dividend-dashboard/getting-started.md) for first-time users
- An MIT license

Next I'll write up how I use the Strategy & overlap tab to spot funds that hold
the same stocks.
