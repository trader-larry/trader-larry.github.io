# About

I've been trading some sort of instrument (stocks/options/futures) since the late 1990's and more actively over the last few years. I also spend time managing a dividend portfolio to create income thru retirement. Technology, specifically computers, has always interested me and most recently I have been spending time using Ai to help create new apps to use for personal use. Using Ai is a big help and cuts back on the learning curve on projects, but I also feel it limits how much we can actually learn ourselves in the process. Maybe the tradeoff of learning how to use Ai vs learning how to write actual code ourselves is worth it in the end. I share some of the tools I (co)create for my own investing and day-to-day work on [GitHub](https://github.com/trader-larry){target="_blank"} in case they're useful to someone else. <a href="https://github.com/trader-larry" target="_blank" rel="noopener noreferrer">GitHub</a>
